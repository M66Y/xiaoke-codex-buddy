# 小克陪伴——Xiaoke Codex Buddy

> 一个会帮你看 Codex 额度，也会提醒你照顾自己的桌面小伙伴。

**Windows 10 / 11 · 当前版本 v1.2**

等 Codex 完成任务的时候，点一下桌面上的小克，就能看到剩余额度、重置时间，还有一张写着关心话语的「小克的小纸条」。

小克陪伴是一款独立的 Windows 悬浮人偶工具。它把额度查询和轻量陪伴放在一起：有一点实用，有一点可爱，也尽量少打扰你。

## 小克能做什么？

### 随手看一眼额度

点击人偶，就能查看 Codex 额度窗口的剩余百分比和重置时间。已有结果会先显示，后台再更新；每次查询都标明更新时间。

### 在等待中陪你一会儿

人偶会随着点击轻轻回弹，纸条也会带着弹性动画展开。问候随时段轮换，还会提醒你喝水、放松眼睛，或者对自己温柔一点。

> 枣尚豪！今天也要开开心心地过呀！

在 Codex 前台累计使用满 **5 分钟**，小克会主动递来一张纸条。离开应用时暂停计时，回来后不会补弹积压的提醒。

### 需要的时候出现

切到其他应用或最小化宿主窗口后，人偶和纸条一起隐藏。纸条连续 **6 秒没有点击**会缩小淡出，点击外部也能立即收起。

## 开始使用

准备好 **Windows 10/11、.NET Framework 4.8**，以及本机已安装、已登录 ChatGPT 账户的 **Codex CLI**。

使用 Git 获取源码，并在 PowerShell 中构建：

```powershell
git clone https://github.com/M66Y/xiaoke-codex-buddy.git
cd xiaoke-codex-buddy
.\scripts\Build.ps1
```

构建完成后，打开 `dist/Q版 Claude娘 Codex 额度查询-v1.2/`，双击同名 `.exe` 即可启动。请保留该文件夹内的图片和配置文件。

构建无需 Python、Node.js 或 NuGet 包。构建检查和项目结构见 [开发说明](docs/DEVELOPMENT.md)。

## 怎么和小克互动？

| 操作 | 小克的反应 |
| --- | --- |
| 点击人偶 | 弹一下，递出纸条并查询额度 |
| 按住人偶拖动 | 调整位置，下次启动时记住位置 |
| 点击纸条内的刷新按钮 | 重新查询额度 |
| 点击人偶或纸条内区域 | 重新开始 6 秒收起计时 |
| 点击纸条外部 | 收起纸条 |
| 右键人偶 | 打开查询、收起和退出菜单 |

手动点击人偶也会重新开始 5 分钟提醒计时。纸条已经打开时，不会用新的定时提醒替换正在看的内容。

<details>
<summary>让小克随登录自动启动</summary>

构建后，在项目根目录执行：

```powershell
& '.\dist\Q版 Claude娘 Codex 额度查询-v1.2\Enable-Autostart.ps1'
```

登录 Windows 后，小克会在后台等待 Codex/ChatGPT 桌面宿主窗口进入前台。

取消自动启动：

```powershell
& '.\dist\Q版 Claude娘 Codex 额度查询-v1.2\Disable-Autostart.ps1'
```

自动启动使用当前用户的启动快捷方式。移动程序文件夹后，需要重新运行启用脚本；退出当前人偶请使用右键菜单。

</details>

## 关于额度和数据

额度来自本机 Codex 的账户接口。查询不发起模型推理，不消耗重置券，也不直接读取或保存登录令牌；纸条文案使用本地预设内容。

宿主在前台时，每分钟后台更新一次。显示值是**标注了更新时间的上次查询结果**，不是逐秒实时读数；缓存只保存在内存中，关闭程序后清除。

## 常见问题

**关闭 Codex 后再次打开，小克没有出现怎么办？**

v1.2 已收到此问题反馈：开机后关闭 Codex，再次启动时，小克可能没有重新出现。目前尚未完成原因定位和修复，不能保证这一流程的自动恢复。

临时处理方式：手动双击解压目录中的人偶 `.exe`。登录自动启动快捷方式只负责登录时启动程序，不会在后台进程退出后自动重启它。

**为什么第一次点击要等几秒？**

首次运行还没有缓存，需要等待本机 Codex 和服务端返回结果。后续点击会先展示已有数据，再按需更新。

**桌面应用已登录，为什么还提示认证失败？**

程序使用本机 Codex CLI 查询。请先执行 `codex login` 完成登录，再点击刷新。额度是否可用还取决于账户、网络和本机 Codex 版本。

**可以在 macOS、Linux 或浏览器里使用吗？**

当前版本面向 Windows，使用 WPF 原生悬浮窗。它独立运行，不会在 Codex 页面里嵌入面板。

**为什么在同一个 ChatGPT 窗口切换页面，人偶仍会显示？**

目前根据 Windows 前台应用窗口判断显示状态，无法区分同一 ChatGPT 窗口内部的不同页面。
